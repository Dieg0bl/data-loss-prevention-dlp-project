# Repository Description

## Proposed "About" Section Description

### English
**Educational cybersecurity project teaching Data Loss Prevention (DLP) policies and implementation. Features hands-on tutorials for creating security policies, implementing USB device restrictions, and applying the principle of least privilege. Includes practical Windows Group Policy configuration, virtualization setup, and real-world case studies. Perfect for cybersecurity students and IT professionals learning enterprise data protection strategies.**

### Spanish
**Proyecto educativo de ciberseguridad que enseña políticas e implementación de Prevención de Pérdida de Datos (DLP). Incluye tutoriales prácticos para crear políticas de seguridad, implementar restricciones de dispositivos USB y aplicar el principio del menor privilegio. Contiene configuración práctica de políticas de grupo de Windows, configuración de virtualización y casos de estudio del mundo real. Ideal para estudiantes de ciberseguridad y profesionales de TI que aprenden estrategias de protección de datos empresariales.**
